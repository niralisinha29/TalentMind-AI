# TalentMind AI - Intelligence Framework

## 1. Current AI Fit Score

Measures a candidate's current AI/ML capabilities based on skills, experience, projects, and assessments.

## 2. AI Potential Score

Measures the candidate's potential to transition into AI roles based on technical foundation, career history, and learning signals.

## 3. Skill Credibility Score

Validates claimed skills using endorsements, assessments, skill duration, and career alignment.

## 4. Hiring Readiness Score

Evaluates hiring feasibility using notice period, profile completeness, recruiter engagement, and availability.

## 5. Final TalentMind Score

Combined score generated using all intelligence metrics to rank candidates effectively.

### Key Differentiators

* Explainable Candidate Ranking
* AI Potential Analysis
* Skill Validation Engine
* Hiring Risk Assessment
* Recruiter Decision Support
