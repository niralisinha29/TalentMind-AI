# Dataset Analysis

## Dataset Structure

Top-Level Fields:

* candidate_id
* profile
* career_history
* education
* skills
* certifications
* languages
* redrob_signals

## Key Observations

* Candidate profiles contain professional summaries and experience.
* Skills include proficiency, endorsements, and duration.
* Career history includes company, title, and duration.
* Redrob signals provide recruiter engagement and hiring insights.
* Dataset supports candidate ranking, AI potential analysis, and hiring intelligence.

## Important Signals

* GitHub Activity Score
* Recruiter Response Rate
* Notice Period
* Open To Work Status
* Skill Assessment Scores
* Profile Completeness Score
